# Website Agenda ALVIC Multimedia TSU

## Deskripsi
Website ALVIC Multimedia TSU merupakan web untuk menampilkan agenda yang ada di profil organisasi dan informasi kegiatan.

## Fitur
- Menampilkan profil ALVIC Multimedia TSU.
- Menampilkan daftar agenda kegiatan.
- Menampilkan nama, kategori, tanggal, dan deskripsi kegiatan.
- Menggunakan data agenda yang disimpan dalam file terpisah.
- Menggunakan fungsi untuk mengamankan teks yang ditampilkan pada halaman web.

## Teknologi
- HTML
- CSS
- PHP
- Laragon sebagai lingkungan pengembangan lokal.

## Struktur Folder
```text
ukm-alvic-agenda/
├── index.php
├── katalog.php
├── data.php
├── functions.php
├── style.css
├── assets/
├── screenshots/
├── README.md
└── .gitignore
```

## Cara Menjalankan
1. Simpan folder proyek di direktori `C:\laragon\www\`.
2. Jalankan Laragon dan aktifkan layanan web server.
3. Buka browser.
4. Akses `http://ukm-alvic-agenda.test` jika virtual host Laragon sudah dikonfigurasi.
5. Klik menu Agenda Kegiatan untuk melihat daftar agenda.
